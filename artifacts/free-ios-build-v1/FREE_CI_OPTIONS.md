# Free CI options — checked 2026-10-26

| provider | free tier / macOS | card | signing | recommendation |
|---|---|---|---|---|
| GitHub Actions | standard macOS runners are free/unlimited for public repos; private usage depends on account allowance | no automatic card required | compilation yes; device signing still external | first choice if public/open-source is acceptable |
| Codemagic individual | 500 macOS M2 minutes/month, one user/concurrency | free plan documented; do not enable billing | compilation yes; signing requires supplied Apple configuration | fallback / private proof-of-concept |

Sources: [GitHub hosted runners](https://docs.github.com/en/actions/reference/runners/github-hosted-runners), [GitHub Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions), [Codemagic pricing](https://docs.codemagic.io/billing/pricing/). Plans and eligibility can change; verify before enabling a provider. No account, card, billing or service was configured by this mission.
